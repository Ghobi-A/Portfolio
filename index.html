Eight intent classes are defined; fatigue and expectation decay have no labelled examples yet.

The question

Can noisy fan discussion reveal actionable interest, rather than simply positive sentiment?

The system

A public-signal pipeline, manually audited intent taxonomy, rule baseline and TF-IDF linear classifiers, surfaced in a Streamlit exploration interface.

Method

Compare rules, logistic regression and SVM variants. Separate actionable detection from intent classification; calibrate with Platt scaling and choose thresholds on validation data.

Evaluation

Group-aware 70/15/15 splits over five seeds. Inspect macro-F1, actionable PR-AUC, calibration, ranking and errors. Two intent classes have no labelled examples; 197 of 200 labels come from YouTube.

Result

Rules lead end-to-end macro-F1 on this small corpus; SVM leads actionable ranking. High split variance makes this preliminary evidence, not a final model ranking.

Technical insight

A stronger ranking model need not be the best multiclass classifier. The metric must match the decision the system supports.

Open PR / not released

PR #23 extends the scope to timestamp-correct weekly demand signals, rolling-origin Bayesian forecasting, coverage monitoring and a shared API/dashboard service. Synthetic marketing-mix experiments remain separate from real audience data. The updated PR reports demo-only findings on a class-stratified 304-row extract: the naive forecast beats the Bayesian model, and no model is recommended. This sample is not volume-representative. Full-dataset evaluation is pending.

Benchmark dashboard ↗GitHub ↗
View case study — Distributed Image ML Pipeline+

The question

Do parallel preprocessing and a different storage format improve the bottleneck—or just one isolated benchmark?

The system

A reproducible flower-image pipeline: Pillow transforms → local/Spark execution → TFRecord shards → TensorFlow CNN → exported benchmark tables.

Method

Keep resize, centre-crop and recompression consistent across execution paths. Separate preprocessing, input throughput and model training measurements.

Evaluation

3,670 JPEGs across five classes, zero failed files. Repeat input benchmarks five times; report variability rather than only the fastest run.

Result

Input throughput improved 4.58×. Mean CNN epoch time barely changed: 8.68 s for JPEG versus 8.54 s for TFRecord, from one seeded three-epoch run per format.

Technical insight

A faster input reader does not imply equivalent end-to-end acceleration when model compute becomes the bottleneck.

Infrastructure merged / evidence pending

Recent Dataproc updates add runtime setup, interpreter selection and cluster-lifecycle fixes. Multi-worker experiments are the intended next scope; the reported speedups above are still single-runner measurements.

The system

A server-rendered TanStack Start application, Supabase database/realtime layer and Stripe integration, with Vercel deployment configuration.

Method

Use server-authoritative validation, signed staff sessions, deny-by-default row-level security, rate limits and idempotent request handling.

View case study — Privacy–Utility and Fairness Audit+
Three distinct audit questions
Formal guarantee

RDP accounting reports achieved ε at δ = 10⁻⁵.

Empirical attack

Loss and LiRA probes test exposure. A failed attack is not a proof.

Group diagnostics

TPR, FPR and disparity require subgroup counts and uncertainty.

The question

Can private training retain useful prediction—and what does the evaluation actually establish?

The system

A repeated-seed private/non-private benchmark with RDP accounting, calibration and fairness analysis, plus loss-based, LiRA-style and canary probes.

Method

Define high-cost labels from the training median and exclude charges from the inputs. Compare DP-SGD against neural and conventional baselines.

Evaluation

Five seeds with achieved epsilon and delta reported. Treat empirical attack outcomes as supplementary tests, not a substitute for the formal guarantee. Small subgroup counts limit fairness interpretation.

Result

At ε ≈ 0.49, mean AUC is .933 versus .953 for HGB—approximately 98% of that baseline’s AUC. The clean smoker task is weak (.537 logistic AUC); the legacy charges proxy gives a misleadingly strong .993.

Technical insight

Auditing uncovered an unwrapped-optimizer, no-noise failure mode. Fixing it and adding regression guards mattered more than polishing a misleading result.

Creative Audio Lab.

Generate an editable musical sketch—not an opaque waveform.

Prompt-conditioned MIDI arrangements built from deterministic music-theory rules, with a small n-gram melody baseline and a rights-aware corpus pipeline.

  3. Next evidenceRights-cleared corpus evaluation

Read the experiment +

The question

Can an editable symbolic generator gain variety without losing harmonic structure?

The system

A typed backend interface, motif analysis, REMI-style tokenisation, MIDI export and a provenance-aware local corpus pipeline.

Method & evaluation

Compare rule and n-gram backends on harmonic fit, novelty, repetition, scale adherence and motif retention. Held-out likelihood and composition-level splits are available for a supplied licensed corpus.

Result & insight

The baseline exposes a novelty–harmonic-fit trade-off. A regression test catches the earlier token-context error that lost pitch history. A working training command is not evidence of real-music generalisation.
